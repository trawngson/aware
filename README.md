# AWARE motion piece: media

- `aware-motion.mp4`: the 60-second film about the AWARE app. 1920×1080,
  60 fps, H.264 (CRF 16) with a 48 kHz stereo AAC soundtrack. The score and
  sound effects are synthesized.
- `preview.webp`: a 14-second looping highlight reel (960×540, 20 fps) cut
  from the film, shown at the top of the main README.

This branch holds only rendered media and shares no history with the code, so
the video never enters the main branch's history. The source that renders it
lives in `video/`; see `video/README.md` to re-render it.
