# AWARE motion piece: master render

`aware-motion.mp4` is the 60-second film about the AWARE app: 1920×1080,
60 fps, H.264 (CRF 16) with a 48 kHz stereo AAC soundtrack. The score and
sound effects are synthesized.

This branch holds only the rendered file and shares no history with the code,
so the video never enters the main branch's history. The source that renders
it lives in `video/` on the `cc/beautiful-ramanujan-7l16nn` branch; see
`video/README.md` there to re-render it.
